Zasady i reguły

Do i nie do
Reguła ✓ Poprawnie ✗ Błędnie
Kolor tekstu color: var(--text-heading) color: #262626 lub color: #0f172a
Tailwind vs. CSS Usuń inline text-[#xxx], ustaw kolor w style.css Mixowanie hardkodowanych klas Tailwind z CSS variables
Nowy komponent na jasnym tle --text-heading nagłówek, --text-main treść, --text-muted meta Nowe odcienie szarości lub nowe zmienne kolorów
Nowy komponent na ciemnym tle #fff, rgba(226,232,240,.88), var(--primary) Używanie --text-heading na ciemnym tle (za mały kontrast)
Specificity Tailwind CDN Selektory z rodzicielskim kontekstem lub usuwaj klasy Tailwind z HTML Zakładanie że style.css zawsze wygrywa z Tailwind
Zaokrąglenia Wartości ze skali: 7, 12, 16, 20, 24, 32, 999px Losowe wartości: 10px, 15px, 18px, 25px
Animacje wejścia IntersectionObserver przez script.js + klasa .visible Animacje CSS bez IntersectionObserver (wszystko animuje się od razu)
